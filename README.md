# portfolio

Personal site. React + TypeScript + Vite, plain CSS.

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # -> dist/
```

Content lives in `src/data.ts`. Project screenshots go in `public/screens/<slug>.png`; if one is missing the card falls back to the SVG in `ProjectArt.tsx`.

Deployed on Vercel.
